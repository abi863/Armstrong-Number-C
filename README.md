
# Armstrong Number Checker in C

## Description
This program checks whether a number is an Armstrong number.

## Example
153 = 1^3 + 5^3 + 3^3 = 153

## Concepts Used
- C Programming
- Loops
- Conditional Statements
- Digit Manipulation
- Arithmetic Operators

## Sample Output
Enter a number: 153
153 is an Armstrong number.

## Compile
gcc armstrong.c -o armstrong.exe

## Run on Windows PowerShell
.\armstrong.exe
